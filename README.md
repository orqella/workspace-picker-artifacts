# Workspace picker artifacts

Prebuilt native sidecar binaries for the private
[`orqella/orqella-workspace-picker`](https://github.com/orqella/orqella-workspace-picker)
module.

The source stays in the private module repository. These artifacts are public so
Orqella can download them without embedding credentials. `sidecars/CHECKSUMS.txt`
contains the SHA-256 digests referenced by the module manifest.
